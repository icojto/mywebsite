# Hristo Portfolio Rebuild

This rebuild uses vanilla HTML, CSS, and JavaScript.

## Main pages
- `index.html` — homepage
- `projects.html` — full archive page

## Main logic file
- `js/app.js` — profile data, filter data, project data, hero slider, project cards, modal, homepage setup, archive setup

## Quick edit points
- change portrait / name / title in `js/app.js` inside `profile`
- add or edit projects in `js/app.js` inside `projects`
- replace images inside `assets/images/`
- replace the CV placeholder inside `assets/files/`

## Extra docs
- `CODE_GUIDE.md` — detailed explanation of the codebase and how to edit it
- `QA_REPORT.md` — static QA pass results

## Notes
- homepage defaults to highlighted projects
- archive page defaults to newest first
- homepage hero now uses one combined surface instead of split portrait/text panels
- both pages use the same popup/modal layout
